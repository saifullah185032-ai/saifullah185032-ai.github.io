# Saif Ullah Portfolio — Updated GitHub Pages Package

## Upload
Copy the contents of this folder to the root of the GitHub Pages repository.

Required structure:

```text
/
├── index.html
├── styles.css
├── script.js
└── assets/
    ├── certifications.json
    ├── favicon.svg
    └── Saif-Ullah-CV.pdf
```

The existing repository's files are not included because the GitHub repository/source was not available in this chat. This package is a clean, self-contained replacement implementation.

## Important
- The CV download button points to `assets/Saif-Ullah-CV.pdf`.
- If your existing CV PDF is better/more complete, replace that file with your current CV while keeping the same filename.
- Project cards deliberately say **REPOSITORY COMING SOON** instead of linking to non-existent repositories.
- Certification data is taken from the supplied LinkedIn certification export. One duplicate `Build RAG Applications: Get Started` entry with the same credential ID was consolidated.
- No unsupported employer dates or current-role details have been invented.

## GitHub Pages
After uploading/committing:
1. Open repository Settings → Pages.
2. Select the branch containing these files and `/ (root)`.
3. Save.
4. Wait for the GitHub Pages deployment to finish.
